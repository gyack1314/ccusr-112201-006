# 材料实验验证与中试候选的证据联动

本项目提供本地合成输入资料、字段约定与完整性检查，不包含待开发的分析、业务判断或交付能力。资料中的名称、设备、机构与结果均非新闻中的真实主体或实际业务记录。

## 环境与现有检查

需要 Python 3.11 或更新版本，仅使用标准库；无需网络、账号或额外依赖。

    python tools/inspect_inputs.py
    python -m unittest discover -s tests -v

现有入口只校验资料的 SHA-256、记录数、字段和主键。资料字段见 docs/资料目录.md，正确性约定见 docs/业务约定.md。新业务能力仍待开发。
