# 业务约定

lot_id 是制备批次，aliquot_id 是分样；同 lot 多测量不构成独立制备。measurement.status 为 valid、invalid、stopped；stopped 不计作零。calibration 的 issued_at 决定获知时间，effective_from/to 决定影响测量期间。sample_stock.quantity 为可用分样数，confirmed_runs 先占用。pilot_terms 的 minimum_performance、max_variance、required_safety 和 material_license 均是资格约束，现有试验仅为合成。

所有记录为本地合成资料；缺失值为 JSON null。资料中的候选操作不是已确认操作。编号仅标识对象，不携带优先级。历史截点以当时已获知事实判断，不以后来的更正冒充当时已知。
